# dashboard_Assinaturas

O Dashboard foi criado usando uma base de dados fictícia de assinaturas de serviços digitais da XBOX. Depois de organizar os dados as seguintes perguntas de negócio foram feitas:
-Pergunta de negócio 1 - Qual faturamento total de vendas de planos anuais (contando todas as assinaturas agregadas)
-Pergunta de negócio 2 - Qual faturamento total de vendas de planos anuais, separado por auto renovação e não auto renovação
-Pergunta de negócio 3 - Total de vendas da assinatura EA play
-Pergunta de negócio 4 - Total de vendas da assinatura Minecraft season pass
Elas foram respondidas usando tabelas dinâmicas. Os valores totais apresentados nelas foram passados para a dashboard para uma melhor vizulização.
